Dashboard - Proyecto Break 1

Dashboard interactivo desarrollado con **HTML, CSS y JavaScript**, compuesto por varios módulos independientes integrados en una sola página principal.

Incluye funcionalidades útiles como reloj digital, clima en tiempo real, generador de contraseñas, gestor de links y notas.

##  Demo Online
 https://eluentorres.github.io/Dashboard---ProyectoBreak-1/

---

## Funcionalidad

### Reloj Digital + Fecha
- Hora en formato 24h con segundos
- Fecha en formato DD/MM/AAAA
- Mensajes dinámicos según la hora del día

###  Estación Meteorológica (WeatherAPI)
- Búsqueda por ciudad
- Información actual del clima
- Temperatura, humedad, viento y precipitaciones
- Previsión por horas
- Mini forecast visible desde el dashboard

###  Generador de Contraseñas Seguras
- Longitud configurable (12 a 50 caracteres)
- Incluye mayúsculas, minúsculas, números y símbolos
- Contraseñas aleatorias seguras

### 🔗 Gestor de Links
- Añadir links con título y URL
- Guardado en LocalStorage
- Eliminación de links
- Persistencia al recargar la página

### 📝 Notas
- Creación de notas rápidas
- Guardado en LocalStorage
- Eliminación de notas
- Vista en miniatura desde el dashboard

###  Background Aleatorio
- Imágenes de fondo aleatorias
- Cambio automático cada 15 segundos
- Compatible con todas las páginas

###  Footer Global
- Footer común cargado dinámicamente para todas las páginas
